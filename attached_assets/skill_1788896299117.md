# 🦊 MMDS Components (Copy)

This skill teaches an AI agent how to use the **🦊 MMDS Components (Copy)** design system. It is useful with or without Figma MCP, and does not assume the user is working inside Figma.

Detailed reconstruction data lives in reference files packaged with this skill. Read those files when you need values, snapshots, or the complete extract. Do not invent missing details.

## Reference files

- `references/components.md`: component variants, composition, and layer snapshots
- `references/variables.md`: variable collections, modes, and values

- `references/styles.md`: paint, effect, and layout grid styles

## Reconstruction rules

These rules apply when rebuilding UI from this skill (with or without MCP):

- Reuse components and variants by name. Nested instances must use that component's snapshot in `references/components.md` (see `use ### Name`).
- Reconstruct from layer snapshots. Copy auto-layout exactly: layoutMode, pack (MIN, MAX, CENTER, SPACE_BETWEEN), counter alignment, itemSpacing, padding, HUG/FIXED/FILL. pack SPACE_BETWEEN is not CSS gap; itemSpacing is a minimum.
- Bound fields: use the variable or style. Snapshot hex is only the mode that was active at scan time.
- Unbound/local fields: copy recorded values exactly (weight, stroke, shadow, radius, padding, vector paths, textAlign, textAutoResize, absolute x,y).
- Paint style kind fill is not always a background; apply fill, stroke, or text fill as the snapshot says.
- Icons are vector path data, not Unicode or SF Symbols.
- If a property is not in the snapshot, it is unknown. Scan warnings are the only allowed gaps.
