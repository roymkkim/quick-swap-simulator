# 🦊 MMDS Components (Copy) typography

## Fonts

Exact families from Figma. Prefer loading these files in the host app. Stack is recorded name, then one CSS generic — not SF Pro or Inter.
If the family is missing, type is incomplete; do not change layout or pick another brand font.

- Geist: Bold w700, Medium w500, Regular w400, SemiBold w600. Stack: "Geist", sans-serif
- Geist Mono: Medium w500, Regular w400. Stack: "Geist Mono", monospace
