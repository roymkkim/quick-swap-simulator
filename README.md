# Quick Swap Simulator

Interactive Quick Swap simulator with a mobile wallet preview, TradingView-style chart, chart-scrubbed header pricing, and a round touch cursor indicator.

## Project

The main artifact lives in [artifacts/quick-swap-simulator](./artifacts/quick-swap-simulator).

## Local development

This workspace uses pnpm. From the repository root:

    pnpm install
    pnpm --filter @workspace/quick-swap-simulator run dev
